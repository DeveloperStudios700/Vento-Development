# Vento Development Website

A modern animated blue-theme website for Vento Development.

## Files

- `index.html` — website structure and content
- `styles.css` — responsive styling and animations
- `script.js` — scroll animations, mobile navigation and cursor glow
- `assets/vento-banner.png` — the Vento Development image supplied for the website

## GitHub Pages

1. Create a new GitHub repository.
2. Upload all files while keeping the `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will publish the site.

## Important

Open `index.html` and replace:

`your-email@example.com`

with Vento Development's real business email address.
